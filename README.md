# China Travel Blog Website

## Project Overview

This project is a responsive travel blog website built for the IT516 course.

The website allows users to explore travel destinations through a clean and responsive interface while demonstrating modern frontend development concepts including:

- Semantic HTML structure
- Responsive CSS layouts
- JavaScript interactivity
- React component architecture
- State management
- Client and Server Components in Next.js

The application is built using React and Next.js and deployed publicly using Vercel.

---

## Features

### Theme Toggle
Users can switch between light mode and dark mode. The selected theme is stored in localStorage so the preference remains saved after refreshing the page.

### Contact Form Validation
The contact form validates user input before submission, including:
- Required field validation
- Email format validation
- Phone number validation
- Success and error feedback messages

### Responsive Design
The website adapts across:
- Mobile devices
- Tablets
- Desktop screens
